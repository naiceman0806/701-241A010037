1. Position Absolute và Relative trong CSS

Relative: Giữ nguyên vị trí trong luồng tài liệu, dịch chuyển tương đối so với chính nó, tạo mốc tọa độ cho phần tử con absolute.

Absolute: Thoát khỏi luồng tài liệu tự nhiên, định vị tuyệt đối dựa trên phần tử cha gần nhất có position khác static.

2. Quy Trình Đăng Ký Domain & Cấu Hình Hosting

Mua domain, trỏ bản ghi DNS về địa chỉ server/hosting. Sử dụng GitHub Pages hoặc Netlify để deploy code tĩnh nhanh chóng không cần server riêng. Cần bật HTTPS để đảm bảo bảo mật dữ liệu.

3. So Sánh Let, Const và Var

Var: Function scope, hoisting có khởi tạo giá trị undefined. Let/Const: Block scope, hoisting nằm trong Temporal Dead Zone. Const không cho phép gán lại giá trị.

4. Event Delegation trong JavaScript

Kỹ thuật gắn sự kiện cho phần tử cha thay vì từng phần tử con dựa trên cơ chế nổi bọt (Event Bubbling), tối ưu hiệu suất bộ nhớ và hỗ trợ tốt cho các phần tử thêm động.
